# Agent tools

Small utilities for working with coding agents.

## Available tools

- [`cx`](tools/cx/README.md) starts Codex in tmux with a companion `lazygit`
  pane and lets the agent keep that pane synchronized with the repository it is
  modifying.
- [`agent-dispatch`](tools/agent-dispatch/README.md) bridges labeled GitHub
  Issues and persistent local Codex threads, including human follow-up through
  issue comments.
